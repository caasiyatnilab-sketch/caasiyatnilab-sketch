# Sentinel Security Journal

This journal is used to record critical security discoveries and learnings.

## 2024-07-07 - Initializing Security Enhancements
**Vulnerability:** Lack of security headers in static portfolio website.
**Learning:** Even static sites can benefit from basic security headers like CSP and Referrer-Policy via meta tags to mitigate XSS and protect user privacy.
**Prevention:** Always include basic security meta tags in HTML templates.
